`scroll-detector.js` identifies a document or large internal vertical scroll root and detects nested scrolling, iframe, horizontal overflow and known virtualized content. `content.js` implements token-scoped scrolling, layout settling, sticky suppression, cancellation and page restoration. Both are classic scripts injected in order into the main frame's isolated world using `chrome.scripting.executeScript`; they do not use ES imports. One isolated-world namespace guards reinjection. These Phase 2 implementation files are unchanged by Phase 3.

**Visible columns** reports sideways overflow as a warning. **All columns** temporarily widens horizontally scrolling descendants and their ancestors within the selected root, then scrolls the root in two dimensions. Original inline property values/priorities and both scroll coordinates are restored on success, failure, cancellation or watchdog expiry. This can change wrapping during the temporary capture layout. Right-to-left roots, unexpandable clipped content, known column virtualization and independent vertical scroll regions are rejected rather than claimed as complete.

`scrollbar-cleanup.js` is injected between the detector and controller. It temporarily hides native scrollbar tracks and thin, content-free horizontal scrollbar widgets, including absolute-positioned floating bars. It excludes table cells and record controls from widget detection. Widgets introduced while scrolling are suppressed before capture; a newly detected widget appearing during a screenshot aborts that attempt. Cleanup restores original visibility and scrollbar geometry before restoring scroll positions.

Phase 3 adds separate `element-selector.js` and `element-content.js` classic scripts in a separate isolated-world namespace. They are injected only for Selected element mode. See [../PHASE3.md](../PHASE3.md) for selection, nested scrolling, cropping and restoration behavior.
